# 강남돼지보살 일일 제작 플레이북

매일 예약 작업으로 실행되는 Claude 세션이 이 문서를 따른다.
**목표:** 오늘 화제 주제를 발굴해 3편을 만들고, 사용자가 직접 올릴 수 있게 **업로드용 zip**으로 전달한다. (인스타 자동 게시는 계정 제한 이후 중단됨 — 절대 approved로 바꾸지 않는다.)

## 0. 준비
- 저장소 `hamdora/saju-cardnews` (push 권한)를 세션에 연결하고 clone.
- `pip install lunar_python pillow numpy --break-system-packages` (한자 폰트: Noto Serif CJK가 없으면 `fonts-noto-cjk` 설치 시도).
- `posts/*/content.json`을 모두 읽어 최근 게시·대기 중 주제를 파악한다(중복 금지).

## 1. 화제 주제 발굴 (매일, 웹 검색 필수)
**목표:** 뉴스·커뮤니티에서 오늘 트래픽이 몰리는 주제 후보 6~8개를 찾고, 그중 3개를 추천한다.

### 1-1. 훑어볼 곳 (검색으로 확인)
- 포털 랭킹: 네이트 랭킹뉴스(연예·종합 조회순/관심순), 네이버·다음 많이 본 뉴스
- 커뮤니티 베스트: 더쿠, 에펨코리아, 디시 실베, 인스티즈, 뽐뿌 등 (집계 사이트 '오늘의베스트' 등도 활용)
- 다가오는 날짜 이벤트: 수능, 대형 출시·개봉·컴백·결혼식, 시상식, 스포츠 결승 등 3~7일 안의 일정
- 해외 빅이슈 중 한국 커뮤니티에서도 퍼지는 것

### 1-2. 후보 점수 (각 1~3점, 합계로 정렬)
| 항목 | 기준 |
|---|---|
| 화제성 | 랭킹 상위·여러 커뮤니티 동시 등장·댓글 수 |
| 사주각 | 생년월일/설립일/사건일이 공개돼 사주로 풀 거리가 있는가 |
| 시의성 | 오늘~사흘 안에 계속 화제가 될 것인가 (예정 이벤트 가산) |
| 안전성 | 3=무해·긍정 / 2=논란이지만 공식 확인된 사실 / 1=의혹·소송 진행 중 |

### 1-3. 반드시 제외
- 사망·참사·범죄 피해자, 미성년자, 선거·정치인, 질병 추측
- 확인되지 않은 의혹·학폭 폭로·열애/임신 추측(반지 등 정황만 있는 것)
- 한 매체·블로그에서만 나온 '단독' 주장 (공신력 있는 매체 2곳 이상 확인 전까지 보류)

### 1-4. 출력
- 후보표: 순위, 주제, 화제 근거(출처 링크), 사주 기준일, 점수, 위험 메모
- 추천 3개: 결이 겹치지 않게(인물 1·기업/작품 1·가벼운 밈/이벤트 1 권장), 14일 내 다룬 주제 제외

## 2. 사주 계산
- `lunar_python`으로 년·월·일주 계산 (정오 기준, 시주는 `??`).
- 사람: 성별로 대운 계산, 한국식 대운수(만 시작 나이) 기준으로 8개 표기.
- 회사·사건: 대운 장 없이 '올해 운' 또는 '당일 일진' 장으로 대체.
- 십신·오행 분포는 코드로 검산한다(일간 대비 음양·생극).

## 3. 원고 (`posts/<slug>/content.json`)
- 기존 `posts/jensen_huang`, `posts/lee_jaeyong`, `posts/samsung_electronics`의 구조와 톤을 그대로 따른다.
- 슬라이드 8장: cover → body(무슨 일/누구인가) → chart → body ① → daeun 또는 body ② → body ③(2026 丙午년 등 올해 운) → closing → outro.
- 본문 한 장 = 2문단, 총 4~5줄. `**강조**`는 빨간색.
- 사실 문장에는 날짜·출처 기반 표현만. 의혹은 "의혹", "보도에 따르면"으로 명시.
- 단정 금지: "범죄 사주", "이혼한다" 같은 예언·낙인 표현 금지. "명리학에서는 ~로 본다" 톤 유지.
- `disclaimer`: "※ 사주 해석은 재미로 봐주세요. 정보는 공개 자료·언론 보도 기준입니다."
- 캡션: 훅 1줄 + 요약 2줄 + 체크 3개 + 질문 + 면책 + 해시태그 8~10개(마지막에 `#강남돼지보살 #pigbosal_saju`).
- **사진:** 웹에서 인물 사진을 가져오지 않는다. `photos/library/<이름>.jpg`가 있으면 사용, 없으면 한자 배경.
- `status: "draft"`, `publish_at`: 다음 날 `T09:00`, `T12:00`, `T19:00` (순서는 화제성 높은 것을 19시).

## 4. 렌더·전달
- `python3 scripts/render_all.py` 후 편마다 8장 미리보기를 한 장으로 합쳐 보낸다.
- 업로드용 zip: 파일·폴더 이름은 **영문만** (예: `cardnews_YYYY-MM-DD.zip` 안에 `0900_<slug>/01.jpg…08.jpg, caption.txt`). caption.txt는 UTF-8(BOM).
- 커밋: `draft: YYYY-MM-DD (slug1, slug2, slug3)` → push. status는 항상 `draft`.
- 사용자가 다른 후보로 바꾸거나 사진을 주면 반영해 다시 보낸다.
